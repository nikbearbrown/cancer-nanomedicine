**Full voiceover:**
"Theranostics starts with a target. An imaging version asks: does this patient's tumor show the target, and where? That creates a visibility check before therapy. A therapeutic version can then deliver radiation to cells with that target. The logic is shared: one target, diagnostic and therapeutic payloads. This changes the decision from 'does this cancer type usually respond?' to 'does this patient's cancer show the target right now?' Theranostics is precision oncology with a built-in scan."
